시즌별 파일 복사

받은 원본 TXT를 유지하고, 원하는 폴더에 새 이름으로 복사합니다.

시즌마다 규칙을 따로 저장할 수 있습니다. 기존 파일을 맞추려면 대상 폴더를 선택하고 같은 파일명 형식으로 미리보기를 확인하세요.

다른 곳에서 받았던 파일도 지정할 수 있습니다. 지정 폴더 바로 아래 TXT만 읽으며 하위 폴더는 포함하지 않습니다. 제목에 시즌이 있으면 지정 시즌만 처리합니다.

기존 시즌 5 폴더를 직접 선택했다면 하위 폴더 규칙을 비워 두세요. 경로는 FF 컨테이너 내부 경로입니다.

번호 보정 예: 원본 1500번을 시즌 304화로 지정하면 1501번은 305화가 됩니다. 원본 번호는 다운로드 목록 순번 또는 기존 파일명 맨 앞 숫자입니다. 제목 인식 방식에서는 기준 번호를 사용하지 않습니다.

{title} 작품명 · {season} 시즌 · {episode} 시즌 회차 · {subtitle} 시즌/회차를 뺀 제목 · {original_number} 원본 번호 · {original_name} 원본 파일명(확장자 제외) · {pid} 회차 ID(기존 파일 폴더는 0). 숫자 자릿수 예: {episode:03d} → 004, {episode:05d} → 00004.

기존 파일명의 ‘304화’ 또는 맨 앞 ‘00304_’ 등을 회차로 읽습니다. 여러 시즌이 섞인 폴더라면 시즌별 폴더를 선택하세요. 인식할 수 없는 기존 이름은 동일 이름 충돌만 확인합니다.

별도 폴더 감시 기능은 아닙니다. 기존 원본 폴더를 지정한 규칙도 해당 작품의 다운로드 작업 후 확인합니다. 먼저 미리보기로 규칙을 확인하세요. TXT를 복사하며 EPUB은 원본 폴더에서 계속 생성됩니다.
