시즌별 파일 복사

받은 원본 TXT를 유지하고, 원하는 폴더에 새 이름으로 복사합니다.

시즌마다 규칙을 따로 저장할 수 있습니다. 기존 파일을 맞추려면 대상 폴더를 선택하고 같은 파일명 형식으로 미리보기를 확인하세요.

다른 곳에서 받았던 파일도 지정할 수 있습니다. 지정 폴더 바로 아래 TXT만 읽으며 하위 폴더는 포함하지 않습니다. 제목에 시즌이 있으면 지정 시즌만 처리합니다.

기존 시즌 5 폴더를 직접 선택했다면 하위 폴더 규칙을 비워 두세요. 경로는 FF 컨테이너 내부 경로입니다.

1. 복사본에 넣을 회차 번호 정하기

제목에 ‘○○화’가 있으면 첫 번째 방법을 선택하세요. 제목에 회차가 없거나 기존 보관 번호에 맞추려면 두 번째 방법을 선택하세요.

제목에 적힌 회차 사용

파일마다 제목에 있는 ‘○○화’를 읽어 복사본 번호로 사용합니다. 앞에 붙은 전체 목록 번호와 시즌 회차가 달라도 괜찮습니다. 기준 번호를 입력할 필요가 없습니다.

설명용 예시 · 아래 숫자는 고정 설정값이 아닙니다. 예시 파일명 규칙: {episode:05d}_{subtitle}.txt

원본 파일명 예시제목에서 읽은 회차복사본 예시
01500_시즌5 304화 각자의 게임(1) - 릴.txt304화00304_각자의 게임(1) - 릴.txt
01501_시즌5 305화 다음 이야기.txt305화00305_다음 이야기.txt

원본 폴더를 비워두면 다운로드 이력에 저장된 제목을 읽고, 별도 폴더를 지정하면 파일명에서 읽습니다. 제목에 ‘○○화’가 없으면 ‘확인 필요’로 표시합니다.

원본 번호를 시즌 회차로 바꾸기

기준으로 삼을 파일 한 개를 정하고, 그 파일의 원본 번호와 원하는 시즌 회차를 입력하세요. 나머지 파일은 같은 차이만큼 번호를 바꿉니다.

예: 원본 번호 1500번인 파일을 기준으로 삼으면 1500 입력

예: 그 파일이 시즌 304화라면 304 입력

계산식: 복사본 회차 = 원본 번호 − 기준 파일의 원본 번호 + 기준 파일의 시즌 회차

설명용 예시 · 기준 원본 번호를 1500, 시즌 회차를 304로 입력했을 때. 예시 파일명 규칙: {episode:05d}_{subtitle}.txt

원본 파일명 예시계산한 회차복사본 예시
01500_각자의 게임(1) - 릴.txt1500 − 1500 + 304 = 304화00304_각자의 게임(1) - 릴.txt
01501_다음 이야기.txt1501 − 1500 + 304 = 305화00305_다음 이야기.txt

기준값은 번호 계산에만 사용합니다. 기준 파일부터 복사하려면 아래 ‘복사할 원본 번호 범위’의 시작 번호도 지정하세요. 계산 결과가 1 미만이면 복사하지 않습니다. 원본 번호에 빈 번호가 있으면 복사본 번호에도 같은 간격이 남습니다.

‘원본 번호’는 어디에서 가져오나요?

2. 복사할 원본 번호 범위 (선택 사항)

어떤 원본 파일을 복사할지 좁히는 설정입니다. 변환하기 전의 원본 번호를 입력하세요. 위에서 계산한 시즌 회차가 아닙니다. 양쪽 모두 0이면 번호로 제한하지 않으며, 지정한 시즌 등 나머지 조건은 계속 적용됩니다.

예: 원본 1500~1510번만 복사하려면 시작 1500, 끝 1510을 입력합니다. ‘1500번 → 시즌 304화’로 보정한 경우 복사본은 304~314화가 됩니다. 시작 1500, 끝 0이면 원본 1500번부터 이후 파일도 대상입니다.

3. 복사본 파일명 모양 정하기

선택하면 아래 파일명 규칙의 회차 번호 자릿수만 바뀌며, 작품명·회차 제목 등 나머지 부분은 유지됩니다. 304화는 3자리 → 304, 4자리 → 0304, 5자리 → 00304입니다. 실제 번호가 선택한 자릿수보다 길면 자르지 않습니다. 예: 2자리로 설정해도 304화는 304입니다. 선택 후 규칙 저장을 누르면 다음 자동 복사에도 적용됩니다. 이미 복사한 파일의 이름은 바꾸지 않습니다.

중괄호 부분은 파일마다 실제 값으로 바뀝니다. {episode:05d}는 회차 번호를 최소 5자리로 표시한다는 뜻입니다. 회차가 12이면 00012, 304이면 00304가 됩니다. 3자리로 맞추려면 {episode:03d}를 사용하세요.

이름 규칙별 설명용 예시

작품명 ‘예시 소설’, 시즌 2, 회차 12, 회차 제목 ‘새로운 시작’인 파일을 가정합니다. 실제 결과는 아래 ‘복사 미리보기’로 확인하세요.

파일명 규칙만들어지는 파일명
{episode:05d}_{subtitle}.txt00012_새로운 시작.txt
{episode:03d}화 {subtitle}.txt012화 새로운 시작.txt
{title} 시즌{season} {episode}화.txt예시 소설 시즌2 12화.txt
{episode:04d}.txt0012.txt
사용할 수 있는 이름 변수 전체 보기
  • {title}: 위에 입력한 작품명
  • {season}: 위에 입력한 시즌
  • {episode}: 선택한 방법으로 정한 시즌 회차
  • {subtitle}: 시즌·회차 표기 뒤의 제목. 회차 표기가 없으면 원본 제목을 사용합니다.
  • {original_number}: 변환 전 원본 번호
  • {original_name}: 확장자를 뺀 원본 파일명
  • {pid}: 다운로드 이력의 회차 ID. 별도 원본 폴더에서는 0

기존 파일명의 ‘304화’ 또는 맨 앞 ‘00304_’ 등을 회차로 읽습니다. 여러 시즌이 섞인 폴더라면 시즌별 폴더를 선택하세요. 인식할 수 없는 기존 이름은 동일 이름 충돌만 확인합니다.

별도 폴더 감시 기능은 아닙니다. 기존 원본 폴더를 지정한 규칙도 해당 작품의 다운로드 작업 후 확인합니다. 먼저 미리보기로 규칙을 확인하세요. TXT를 복사하며 EPUB은 원본 폴더에서 계속 생성됩니다.
